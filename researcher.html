Platform health

public.monitor_health, last 7 nights

The nightly sweep closes runs that were left open by a browser that went away. It runs at 02:00 Kuwait time as a scheduled job, not from anybody's laptop, and it writes a row whether it finds anything or not - so a missing night is visible rather than silent. The table it writes to carries counts only: no run id, no mission id and no researcher id may ever be added to it.

What the record is for

Row level security scopes every table on this page to the signed-in account. Another researcher signed in to this same workspace sees their own missions, their own runs, their own steps and their own findings, and nothing of yours — the filter is a database policy on auth.uid(), not a query this page writes, so it cannot be turned off from a browser. The payload archive is the one shared table, and it is read-only for every signed-in role.
