Automation section — standalone check

Owner: 04 · Automation and agents. This page exists so the panel can be opened, clicked and read on its own, with no database and no n8n behind it. It is not the demo screen. The demo screen is index.html at the repo root — the site at kuwait-sat1-hub.vercel.app — and the panel it loads is js/ksat-workflow.js.

This is a REPLAY, not the database — and not the shipped panel either. The panel below is js/automation.js in this folder: the reference implementation, written against the n8n write path, where the agents run on a worker and the browser polls my_agent_steps for their rows. The site ships js/ksat-workflow.js instead, which runs the same six steps in the page and writes them through researcher_log_step(). 04-agents/README.md has the mapping between the two, line by line. (This paragraph said "the same one mission.html loads" until 21 Sep 2026. There is no mission.html in this repo and there never was — a sentence that would have been read out beside a judge.)

The Supabase client underneath the panel is faked in this page and answers out of agent/run.js, the same file the n8n Code node runs. So the order of the steps and the decision are real. The zone scores, the cooling projections and every row are sample values: not KuwaitSat-1 measurements, and not rows in Supabase. Say that out loud if a judge is looking at this page.
